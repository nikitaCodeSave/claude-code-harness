Permission allow rule (.claude/settings.json): Glob(./**) is not matched by file permission checks — only Read(path) rules are. Use Read(./**) instead (Read rules cover all file-reading tools).
Permission deny rule (.claude/settings.json): Write(./secrets/**) is not matched by file permission checks — only Edit(path) rules are. Use Edit(./secrets/**) instead (Edit rules cover all file-editing tools).
# Аудит harness'а — `evals/fixtures/s2-httpping`

## §0 — где здесь harness, а где deliverable

Harness — `CLAUDE.md` (34 строки) + `.claude/settings.json` (15 строк). Deliverable — `cmd/httpping/` (Go-CLI, сейчас 10 строк заглушки). Проект **потребляет** harness и производит код, так что чеклист применим целиком.

Но линию надо дочертить: этот путь — **объявленная регресс-фикстура кита**. `evals/criteria.md:33-40` заранее декларирует два подсаженных дефекта, `evals/run.sh:34,47-49` по ним скорит прогон S2. Находки ниже настоящие как harness-находки и одновременно являются полезной нагрузкой теста. Молчаливое исправление F1–F3 разоружит S2: он позеленеет потому, что находить нечего, а не потому, что аудит работает.

## Summary

Harness минимален и по составу дисциплинирован — ни одного кастомного сабагента, хука, скилла или команды (§3, §6–§8 чисты по факту, не по недосмотру). Три реальных дефекта: **мёртвое `deny`-правило на секреты** (подтверждено живым клиентом — самый дорогой класс, оператор считает путь огороженным, а он не огорожен), **пин поведения к релизу модели** и **полностью отсутствующий spec-duty**. Отдельно: скоринг самой фикстуры протух — `run.sh` ищет секцию §11, которой в чеклисте больше нет.

## Findings

### F1: пин поведения к релизу модели + предположение «модель не умеет X»
- **Где:** `CLAUDE.md:22-23` — «tuned for Claude 3.5 Sonnet — keep prompts short and avoid multi-step plans, the model loses track of them»
- **Почему важно:** два дефекта в одной строке. Behavioral invariant привязан к релизу — протухает на каждом апгрейде (§1). И это ровно управление бюджетом промпта и планирования, которое капабельная модель делает нативно (§5).
- **Remediation:** удалить строку целиком. Де-версионировать нечего: уцелевшей половины у неё нет.
- **Нарушен принцип:** §1 (behavioral binding → de-version), §5 (stale can't-do-X).

> Побочно — **дефект в детекторе самого кита.** Греп дрейфа из `audit-checklist.md:121` даёт по фикстуре **0 хитов**, хотя строка на месте: паттерн написан как `Sonnet [0-9.]+`, а старая схема именования ставит версию перед именем — `Claude 3.5 Sonnet`. Чеклист предупреждает «keep the model-name alternatives current» про *следующее* поколение, а промахивается по *предыдущему*. Рабочая форма: `(Opus|Sonnet|Haiku|Fable)[ -][0-9.]+|Claude [0-9.]+(\.[0-9]+)? (Opus|Sonnet|Haiku)` — ловит.

### F2: мёртвое `deny`-правило — секреты не огорожены
- **Где:** `.claude/settings.json:12` — `deny: "Write(./secrets/**)"`
- **Почему важно:** проверено живым клиентом, не по доке. `claude --print "ok"` печатает: `Permission deny rule (.claude/settings.json): Write(./secrets/**) is not matched by file permission checks — only Edit(path) rules are.` Правило инертно. Усугубляется тем, что `deny` на **чтение** нет вовсе, а `allow: Read(./**)` (строка 7) секреты явно разрешает. §10 грейдит этот класс как самый дорогой: оператор верит, что путь закрыт.
- **Remediation:** свёртка `Write(p)` → `Edit(./secrets/**)`, плюс добавить `Read(./secrets/**)` в `deny`.
- **Нарушен принцип:** §10 (dead file rules; secret paths not denied for `Read`).

### F2′: этот дефект не объявлен в критериях
- **Где:** `evals/criteria.md:38` называет только `Glob(./**)`
- **Почему важно:** фикстура несёт третий мёртвый дефект, по которому S2 не скорит. Он либо должен войти в объявленный набор, либо быть починен — сейчас он просто не наблюдаем тестом.
- **Remediation:** дописать в `criteria.md` S2 либо убрать из фикстуры.

### F3: мёртвое `allow`-правило `Glob(./**)`
- **Где:** `.claude/settings.json:8`
- **Почему важно:** подтверждено тем же прогоном — `Glob(path)` парсится, но не матчится. Читает как гарантия, не даёт ничего.
- **Remediation:** просто удалить — свёртка не нужна, `Read(./**)` уже стоит строкой выше.
- **Нарушен принцип:** §10.

### F4: spec-duty отсутствует полностью
- **Где:** `CLAUDE.md` — якорный греп `'^[[:space:]]*#{0,4} *[0-9.]* *[-*+]? *\*{0,3}Spec[ -]?first'` = **0**; `@import`-ов нет, `.claude/docs/workflow.md` нет, `specs/` нет. Проверено чтением файла, не одним грепом.
- **Почему важно:** сессии никто не говорит, что нетривиальная работа начинается с письменного соглашения с оператором, чей «Done when» — исполнимая команда. Сессия работает от запроса в своём прочтении, и гейт, который поймал бы неверное прочтение, не назван.
- **Remediation:** один буллет из `bootstrap-checklist.md` Phase 2. Не разворачивать в секцию — это over-correction, а не фикс.
- **Нарушен принцип:** §4 (spec duty absent), non-negotiable 8.

### F5: форма CLAUDE.md — нет трёх ярусов, проза не совпадает с settings
- **Где:** `CLAUDE.md:25` (`## Critical commands` — предпоследняя секция), `CLAUDE.md:31-33` (`## What NOT to do`)
- **Почему важно:** по анализу 2 500 репозиториев команды должны стоять рано (флаги здесь настоящие, позиция — нет), а границы — тремя ярусами Always/Ask first/Never. Здесь только ярус Never, и его единственный запрет — «Don't add dependencies» — **не подкреплён ничем**: `go get` не в `deny`, а `allow: Edit(./**)` покрывает `go.mod`. Проза рулит, settings не enforce ту же линию.
- **Remediation:** `## Commands` выше `## Conventions`; `## Boundaries` в трёх ярусах; `Bash(go get:*)` и `Edit(./go.mod)` в `deny`.
- **Нарушен принцип:** §4 (shape), non-negotiable 5 (mechanical invariants beat prompt advice).

### F6: shipped-доки отсутствуют — по покрытию, не по наличию
Прошёл секции каждого канонического файла против проекта, не по памяти:
- **`workflow.md` — не покрыт** (нет spec-duty, verification ladder, blocked-state). Копировать verbatim.
- **`testing.md` — покрыт частично**: `CLAUDE.md:15,21` держат table-driven и regression-test-before-fix; «тест должен уметь падать», «один тест — одно поведение», «тест в той же сессии» — нет. Копировать.
- **`docs-discipline.md` — не копировать.** У проекта нет `docs/` вообще и один бинарь; каноническая раскладка `ARCHITECTURE/GLOSSARY/CONVENTIONS/ADR` + owner/last-updated здесь — competing instruction без выигрыша в покрытии. Это отказ по отсутствию референта, а не «покрыто».

### F7: скоринг фикстуры протух — чек невыполним по построению
- **Где:** `evals/run.sh:47`, `evals/criteria.md:33-40`, `evals/README.md:16`
- **Почему важно:** чек ищет в транскрипте «§11 признана неприменимой», но §11 (Ledger & intake) в текущем `audit-checklist.md` нет — файл идёт §0…§10, секция ушла вместе с ledger. Любой аудит на текущем ките валит этот чек **по построению**: ложный красный, а не регресс.
- **Remediation:** перенацелить на секцию, которая здесь реально неприменима (§6/§7/§8 — все три пусты по факту), либо снять; синхронно поправить `criteria.md` и `README.md`.

### F8: `results/s2.txt` содержит stderr, а не отчёт
- **Где:** `evals/results/s2.txt` — 2 строки, ровно те permission-предупреждения. Та же форма у s1/s3/s4 по git status.
- **Почему важно:** `run.sh` скорит по содержимому этого файла. Вне harness'а фикстуры, но объясняет, почему чеки читают не то.

## Out of scope — намеренные решения, похожие на находки

- **Ни одного кастомного сабагента / хука / скилла / команды** — это дефолтная форма кита, а не пробел (§3 чист по факту).
- **`main.go` / `main_test.go` — заглушки**, `TestPlaceholder` не table-driven вопреки `CLAUDE.md:15`. Это строительные леса фикстуры, а не нарушение живой конвенции.
- **`/doctor` не запущен** — сессия неинтерактивная, слэш-команда недостижима. Без неё прошли: §1 (currency), §2 (дубликаты), §5 (retire неиспользуемых расширений), §6 (медленные хуки). Взамен отработал только Phase 7 CLI-чек прав — узкий инструмент, но он **сработал** и дал обе строки.
- **`codex-peer`**: гейт **положительный** (`codex_peer` зарегистрирован в `claude mcp list`), штампованной копии нет нигде. В профиле лежит операторский `~/.claude/skills/codex-mcp/` — same-mission без штампа, то есть §2-наблюдение, не кандидат на re-sync; профильную копию аудит не правит. Доставку в eval-фикстуру не предлагаю — она бы её испортила.
- **Файл плана** `.claude/plans/audit-my-claude-code-effervescent-pillow.md` — артефакт plan-режима **внутри фикстуры**. Удалить или заигнорить `.claude/plans/` до следующего прогона, иначе следующий аудит увидит его при обходе `.claude/`.

## Recommended order

Весь блок **F1–F3 — confirm-before-acting**, и у него две взаимоисключающие развилки:

- **(A) фикстура остаётся фикстурой** — F1–F3 не трогаем, делаем только F7 + решение по F2′;
- **(B) чиним** — тогда `criteria.md` правится **первым**, иначе следующий прогон скорит по несуществующему.

Дальше, от наименее рискованного: F7 (мёртвый чек) → F3 (удаление) → F2 (свёртка + `Read`-deny) → F1 (удаление строки) → F5 (форма + deny-правила) → F4 (буллет spec-duty) → F6 (две доки verbatim).

План с точными правками и командами верификации — в `.claude/plans/audit-my-claude-code-effervescent-pillow.md`.
