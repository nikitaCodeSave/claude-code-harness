Permission allow rule (.claude/settings.json): Glob(./**) is not matched by file permission checks — only Read(path) rules are. Use Read(./**) instead (Read rules cover all file-reading tools).
Permission deny rule (.claude/settings.json): Write(./secrets/**) is not matched by file permission checks — only Edit(path) rules are. Use Edit(./secrets/**) instead (Edit rules cover all file-editing tools).

## Findings

**F1 · `CLAUDE.md:22-23` — поведенческий пин к релизу модели · подсажен · §1 + §5**
«This project is tuned for **Claude 3.5 Sonnet** — keep prompts short and avoid multi-step plans, the model loses track of them». Две болезни в одной строке: binding инварианта к релизу (§1) и предположение «модель не умеет X» (§5). Провенанса нет — это не «измерено тогда-то», а действующая инструкция, уцелевшей половины не остаётся. Ремедиация: удалить обе строки.

**F2 · `.claude/settings.json:8` — мёртвое `allow` · подсажен · §10**
`"Glob(./**)"`. Измерено, не выведено из доки: собственный stderr этого прогона, `evals/results/s2.txt:1` — *«Glob(./\*\*) is not matched by file permission checks — only Read(path) rules are»*. Это ровно оракул Phase 7. Ремедиация по чеклисту — свёртка, не удаление: `Glob(p)` → `Read(p)`; здесь схлопывается в удаление, `Read(./**)` уже стоит строкой выше.

**F3 · `.claude/settings.json:12` — мёртвое `deny` · НЕ объявлено · §10**
`"Write(./secrets/**)"`, `results/s2.txt:2`. §10 называет мёртвый deny **самым дорогим классом дефектов харнесса**: оператор считает путь огороженным, а он открыт — живым замером `deny: Write(./s/**)` позволил создать файл. Свернуть в `Edit(./secrets/**)`. Этот дефект сильнее обоих объявленных и уже лежит в фикстуре бесплатно.

**F4 · секреты разрешены к чтению · НЕ объявлено · §10**
`allow: Read(./**)` (:7) при полном отсутствии `Read` в `deny`. Phase 3: путь, который нельзя ни читать, ни менять, требует обоих правил. Добавить `deny: Read(./secrets/**)`. Честная оговорка: каталога `./secrets/` нет — находка не в утечке, а в том, что намерение выражено правилом, которое ничего не делает.

**F5 · единственный жёсткий запрет без механического носителя · НЕ объявлено · §4 + §10**
`CLAUDE.md:33` «Don't add dependencies» против settings, где нет ни `go get`, ни `go.mod`, при живом `allow: Edit(./**)`. §4 требует совпадения яруса Never с `deny`. Ремедиация: `deny: Bash(go get:*)` + `ask: Edit(./go.mod)` (не deny — бамп версии Go легитимен).

**F6 · форма CLAUDE.md, шесть write-through грепов Phase 7 = 0 · НЕ объявлено · §4**
33 строки — размер в норме, вопрос к форме. Настоящее (а не артефакт грепа): команды с реальными флагами стоят **предпоследней** секцией вместо ранней; `## What NOT to do` — один ярус вместо трёх и без зеркала в settings; **spec-duty отсутствует** — файл прочитан целиком, это не ложный провал. Ремедиация: поднять Commands, три яруса Boundaries, **один** буллет spec-duty (14-строчная секция — перекоррекция, а не починка).

**F7 · shipped-дистилляция отсутствует, покрытие обойдено по секциям · НЕ объявлено · §4**

**F8 · детектор дрейфа §1 не видит подсаженный пин · находка против КИТА · `audit-checklist.md:121-122`**
Замер с положительным и отрицательным контролем: регексп матчит постфиксную форму (`under Opus 5`, `claude-sonnet-5`) и **не матчит префиксную** (`Claude 3.5 Sonnet`, `Claude 3 Opus`). ## Диспозиция — и она неудобная

**Находки в фикстуре не являются целями правки.** Молчаливо починить F1/F2 — разоружить S2. Починить F6/F7, «отбутстрапив» фикстуру по дефолтной форме кита, — сломать глубже: S2 существует ровно для того, чтобы измерять аудит обычного маленького проекта, до которого кит не доезжал.

Рекомендую **(A)**: фикстуру не трогать, исполнить только два пункта **вне** аудируемого каталога — **F8** (регексп детектора) и **F9** (ограждение). Опционально дописать **F3** третьим объявленным дефектом в `criteria.md`; порядок обязателен — сначала `criteria.md`, иначе следующий прогон скорит по несуществующему (эта ошибка уже случалась с ретайренным критерием «§11»).

**(B)** — ремонтировать фикстуру как живой проект: тогда `criteria.md` переписывается первым. Цена: S2 начинает измерять аудит харнесса, который кит сам и построил, — тавтологический тест.
