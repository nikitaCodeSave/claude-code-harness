# Пять агентов документации проверили инвентарь: три правки, четыре ложные тревоги

## Контекст

Оператор попросил детальную верификацию кита совместно с агентом документации Claude Code. Пять
`claude-code-guide` параллельно: четыре по зонам `native-capabilities.md` (сабагенты/workflows;
hooks/effort/review/doctor; memory/skills/MCP/plugins; settings/permissions), пятый — по всем
остальным файлам плагина, с задачей ловить утверждения о Claude Code, а не дизайн-мнения.

Ключевая деталь постановки: агентам был задан различающий вердикт. `CONTRADICTED` (дока говорит
иное) отделён от `NOT_IN_DOCS` (дока молчит) — иначе binary-verified факты кита, которых в
публичной доке нет по построению, посыпались бы как «ошибки».

## Изменения

**Version pin → v2.1.226.** Единственный version-pinned документ кита отстал на релиз от
собственного refresh-ledger — ровно та тихая протухаемость, ради которой пин и единственный.

**Ultrareview → ~$5–25 за прогон** (первоисточник сейчас даёт более широкую вилку, чем несла
запись), плюс статус research preview и правила бесплатных прогонов: три на Pro/Max — разовые, не
обновляются, а прерванный прогон всё равно съедает один.

**`/fork` получил условие**: при выключенном agent view `/subtask` не существует, и форк-сабагента
запускает именно `/fork`. Harness-шаг, зашивший одно имя команды, ломается на другой конфигурации.

## Затронутые файлы

- `plugins/harness/references/native-capabilities.md` — три правки
- `CHANGELOG.md`, оба `plugin.json` → 1.21.7

## Проверка

Все находки уровня high проверены здесь, а не приняты с чужих слов, — и **четыре из них
рассыпались**:

- «`Grep(path)` покрыт Read-правилами, значит кит противоречит доке» — кит ровно это и говорит.
  Живая проба на 2.1.226: `deny: Write(./s/**)` не помешал создать файл, при старте пришли три
  предупреждения (Write/Glob/NotebookEdit), а по `Grep(path)` — ни одного. Утверждение кита в
  силе.
- «Невалидный `defaultMode` не *silently* обнуляет файл» — дифференциальный оракул: с валидным
  режимом ключ `language: french` применился (ответ по-французски), с невалидным — нет, и в stderr
  ничего. Тихо, как и написано.
- «`sandbox.network.strictAllowlist` — возможно, неверное имя» — в бинаре 2.1.226 присутствует с
  описанием «deterministically denies hosts not in the allowlist».
- «`"."` как skills-путь плагина не документирован» — в схеме манифеста: `Path to a skill
  directory, relative to the plugin root ("." / "./" denote the plugin root itself)`.

Сверх того первоисточник **подтвердил** снятие лимита на общее число сабагентов за сессию («no
limit on the total number of subagents Claude can spawn over a session») и поимённо — все 31
hook-события.

```bash
./evals/run.sh mech          # 9/9 PASS, локстеп 1.21.7, битых ссылок 0
```

Non-claims: агенты работали по официальной доке и бинарю, а не по всем поверхностям кита; зоны
`practice-baseline.md` и `codex-peer-skill.md` проверены поверхностно. Один кандидат в пропуски не
внесён намеренно (managed-настройка, блокирующая не-плагинные источники кастомизации для
skills/agents/hooks/mcp) — решение о добавлении за оператором.
