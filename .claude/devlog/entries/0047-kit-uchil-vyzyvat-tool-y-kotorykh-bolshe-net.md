# Кит учил вызывать tool'ы, которых больше нет

## Контекст

Ledger стоял на CC v2.1.226 (8 августа), живой клиент — v2.1.251. Двадцать пять релизов дельты,
из них три недели пришлись на период, когда Anthropic выпускал по несколько версий в неделю.
Внешний интейк по процедуре `harness-evolution.md` Pass 1.

Большая часть дельты — новая нативная поверхность, к которой кит должен роутить вместо
самодельного эквивалента. Но два места оказались хуже, чем «устарело»: следование тексту кита
буквально привело бы к вызову того, чего нет.

## Изменения

**Agent teams переписаны целиком.** Кит описывал вход через `TeamCreate` / `TeamDelete` —
оба tool'а удалены в v2.1.178, а `team_name` на Agent tool принимается и игнорируется. Секция
теперь несёт то, что реально управляет командой: `teammateMode` (in-process по умолчанию с
2.1.179), цепочка приоритета модели (`CLAUDE_CODE_SUBAGENT_MODEL` ▸ промпт ▸ определение агента ▸
модель лида), авто-аппрув плана teammate'а лидом без ревью оператора, пути mailbox/task-list,
лимиты.

Главное добавление — не справочное: **включение флага меняет обычное делегирование**. Субагент,
которому Claude сам дал имя, стартует как teammate, то есть команда собирается во время работы,
которую никто не формулировал как командную, по цене teammate'а. Это следствие продублировано в
`harness-discipline.md` — там, где кит говорит «document, don't enable».

**Потолок вместо ошибки.** Кит утверждал, что `xhigh`/`max` при выключенном thinking даёт 400.
С 2.1.251 клиент перехватывает связку и шлёт `high` — то есть отказ стал **тихим потолком**.
Формулировка «вернётся ошибка» здесь опаснее устаревшей: она обещает сигнал, которого не будет.

**Deny-правило — гигиена, а не containment.** v2.1.251 закрыл четыре обхода разрешительного слоя
(подмена симлинка после пройденной проверки в Read/Write/Edit; `Read(...)`-deny вообще не
применялись к путям Grep/Glob через симлинк; `scriptPath` у Workflow читался до проверки;
арифметические присваивания авто-аппрувились в Bash). Отсюда два следствия в тексте: enforcement
— свойство релиза, поэтому клиент надо держать свежим; а против состязательного обхода работает
sandbox, не deny. Плюс новая находка в `audit-checklist.md` §10.

**Аудит начинается с нативного прохода.** Новая §0.5 — сначала `/doctor`, и явный список того,
что он покрывает (мёртвый вес skills/MCP/plugins по реальным счётчикам использования,
rightsizing CLAUDE.md, медленные хуки, непарсящиеся настройки, актуальность версии) против того,
что он структурно не видит (закоммиченные файлы и все findings, требующие суждения). Bootstrap
Phase 7 открывается тем же. Это ровно дисциплина кита, применённая к самому киту: не проходить
руками по земле, которую инструмент уже прошёл.

**Остальные фолды:** `--restricted` как отгруженный read-and-reason профиль; `subagent_type:
"fork"` (наследует беседу и prompt-cache — и авторскую рамку, поэтому не годится для независимого
рефьютера); смена семантики `CLAUDE_CODE_SUBAGENT_MODEL` с override на default; TTL prompt-кеша
для делегатов; `/tasks` печатает модель и effort каждого субагента (снимает главный повод писать
`subagentStatusLine`-скрипт); `PreModelSwitch`/`PostModelSwitch` (хуков стало 33 — 31 в доке плюс
два, проверенных в бинаре); `Concise`; `notify_when_idle`; `/effort` с дефолтом на модель.

**`evidence-base.md` +3 источника**, из них один самоценный: **v2.1.232 убрал стартовую подсказку
«создай кастомного субагента»**. Вендор ретайрит собственный nudge — это first-party
подтверждение built-ins-first, а не наша интерпретация. Плюс agent-teams doc (T1) и открытие
Codex-харнеса под Apache-2.0 с харнес-онли свингом 13.3% → 38.3% на ARC-AGI-3 при ~6× меньшем
расходе токенов (**T4, vendor-claim** — corroboration Harness-Bench, инвариантов не порождает).

## Верификация

- `strings` по бинарю 2.1.251: `PreModelSwitch` (40 вхождений), `PostModelSwitch` (18),
  `CLAUDE_CODE_RESTRICTED` (9), `CLAUDE_CODE_SUBAGENT_MODEL` (5), `promptCacheTtl` /
  `subagentPromptCacheTtl` (6/6), `modelPicker` (17), `ANTHROPIC_DEFAULT_MODEL` (10),
  `teammateMode` (17) — прямой grep по Bun-ELF даёт ложные негативы, поэтому только через
  `strings`.
- `code.claude.com/docs/en/hooks` перечитан целиком: 31 событие; расхождение с бинарём (33)
  зафиксировано в тексте как «фича доехала до бинаря раньше доки», а не замолчано.
- `code.claude.com/docs/en/agent-teams` перечитан целиком — источник всех фактов секции.
- Drift-детектор `audit-checklist.md` §1 прогнан по репо: выживших хитов, кроме легитимной
  провенанс-разметки и цитат, нет.

## Результат

Интейк вошёл в релиз **v1.23.0** вместе со strip-ревизией той же сессии (#48) — отдельного
1.22.0 не было: обе части едут одним номером, потому что ни одна не была закоммичена по
отдельности.
