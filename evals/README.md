# evals — регресс-набор кита (v2)

Проверяет, что кит цел и что скилл на реальных состояниях проекта ставит то, что обещает.
Критерии — в `criteria.md`, объявлены **до** прогонов; транскрипты — в `results/`.

```bash
./evals/run.sh mech       # статика: секунды, бесплатно — перед каждым релизом
./evals/run.sh sessions   # три headless-прогона A/B/C, ~10 мин, подписка
./evals/run.sh all
```

- `mech/kit_consistency.sh` — json и шаблоны парсятся, ссылки целы, версии плагинов в локстепе,
  `SKILL.md` называет каждый шаблон, бюджеты шаблонов, нет пинов версий, нет мёртвых форм правил в
  шаблоне `settings.json`. Каждая проверка проверена на падение подложенным дефектом.
- `fixtures/greenfield/` — пустой репо (A: новый большой проект).
- `fixtures/monorepo/` — три компонента со своими командами, общий контракт, запрет только в
  README, решения с причинами в `docs/decisions.md` (B: существующий многосоставный проект).
- `fixtures/s2-httpping/` — harness с двумя подсаженными дефектами (пин к `Claude 3.5 Sonnet`,
  мёртвое правило `Glob(./**)`) (C: существующий harness, read-only).
- `results/v1/` — прогоны 1.x, историческая справка.
